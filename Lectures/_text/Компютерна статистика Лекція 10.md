## §1. Поліноміальна схема Бернуллі та оцінка ОМВ

Нехай $X = (\xi_1, \dots, \xi_n)$ — кратна вибірка, де

$$\xi_j \in \{x_1, \dots, x_k\}, \qquad P(\xi_j = x_i) = p_i, \qquad \sum_{i=1}^{k} p_i = 1, \quad p_i > 0.$$

Невідомий параметр $\theta = (p_1, \dots, p_k) \in \Theta$. Такий об'єкт називається **поліноміальною схемою Бернуллі**.

> **Означення 1 (частоти)**
>
> **Абсолютною частотою** значення $x_i$ у вибірці називається
>
> $$\nu_{ni} = \sum_{j=1}^{n} \mathbf{1}_{\{\xi_j = x_i\}}, \qquad \nu_n = (\nu_{n1}, \dots, \nu_{nk}), \qquad \sum_{i=1}^{k} \nu_{ni} = n.$$
>
> **Відносними частотами** називаються
>
> $$\hat{p}_n = \frac{\nu_n}{n} = \left(\frac{\nu_{n1}}{n}; \dots; \frac{\nu_{nk}}{n}\right), \qquad \sum_{i=1}^{k} \frac{\nu_{ni}}{n} = 1.$$

Параметр $\theta$ невідомий, і його треба оцінити. Знайдемо $\hat{\theta}_{\text{ОМВ}}$.

**Функція правдоподібності**

Ймовірність окремого спостереження

$$P(\xi = \xi_j) = \prod_{i=1}^{k} p_i^{\mathbf{1}_{\{\xi_j = x_i\}}} \ \left(= \sum_{i=1}^{k} p_i \, \mathbf{1}_{\{\xi_j = x_i\}}\right),$$

тому

$$L(X, \theta) = \prod_{j=1}^{n} P(\xi = \xi_j) = \prod_{j=1}^{n} \prod_{i=1}^{k} p_i^{\mathbf{1}_{\{\xi_j = x_i\}}} = \prod_{i=1}^{k} p_i^{\sum_j \mathbf{1}_{\{\xi_j = x_i\}}} = \prod_{i=1}^{k} p_i^{\nu_{ni}} \ \longrightarrow \ \max_{\theta}.$$

**Логарифм правдоподібності**

$$\ln L(X, \theta) = \sum_{i=1}^{k} \nu_{ni} \ln p_i \ \to \ \max.$$

Безумовна похідна $\dfrac{\partial}{\partial p_i} \ln L(X, \theta) = \dfrac{\nu_{ni}}{p_i} = 0$ *розв'язку не має*, бо ми забули про обмеження $\sum p_i = 1$. Отже, розв'язуємо задачу на умовний екстремум:

$$\begin{cases} \displaystyle\sum_{i=1}^{k} \nu_{ni} \ln p_i \ \to \ \max, \\ \displaystyle\sum_{i=1}^{k} p_i = 1. \end{cases}$$

**Метод множників Лагранжа**

$$\mathcal{L} = \sum_{i=1}^{k} \nu_{ni} \ln p_i + \lambda \left(\sum_{i=1}^{k} p_i - 1\right) \ \to \ \max.$$

Диференціюємо:

$$\frac{\partial \mathcal{L}}{\partial p_i} = \frac{\nu_{ni}}{p_i} + \lambda = 0 \implies p_i = -\frac{\nu_{ni}}{\lambda}, \qquad i = \overline{1, k}.$$

Підставляємо в умову нормування:

$$1 = \sum_{i=1}^{k} p_i = -\sum_{i=1}^{k} \frac{\nu_{ni}}{\lambda} = -\frac{n}{\lambda} \implies \lambda = -n \implies \hat{p}_i = \frac{\nu_{ni}}{n}.$$

Отже,

$$\boxed{\hat{\theta}_{\text{ОМВ}} = \frac{\nu_n}{n}}$$

— оцінкою максимальної правдоподібності є вектор відносних частот.

Оцінка консистентна: $\forall i \in \{1, \dots, k\}$

$$\hat{p}_i \xrightarrow{\text{м.н.}} p_i, \qquad \hat{p}_i \xrightarrow{P} p_i, \qquad n \to \infty,$$

бо $\mathbf{1}_{\{\xi_j = x_i\}} \sim B(p_i)$.

## §2. Асимптотика відносних частот. Гіпотези

Оскільки $\nu_{ni} \sim B(n, p_i)$, маємо

$$\mathrm{E}\hat{p}_i = p_i, \qquad \mathrm{D}\hat{p}_i = \frac{p_i(1 - p_i)}{n}, \qquad \frac{\sqrt{n}\,(\hat{p}_i - p_i)}{\sqrt{p_i(1 - p_i)}} \xrightarrow{\omega} N(0, 1).$$

**Гіпотези для поліноміальної схеми Бернуллі**

$$\text{I)} \begin{cases} H_0: \ \theta = \theta_0, \\ H_1: \ \theta \neq \theta_0; \end{cases} \qquad \text{II)} \begin{cases} H_0: \ \{\xi_i\} \text{ — незалежні}, \\ H_1: \ \{\xi_i\} \text{ — залежні}. \end{cases}$$

**Нагадування**

У попередніх темах критерії будувалися на статистиках зі збіжністю до нормального розподілу та до $\chi^2$:

$$\frac{\sqrt{n}\,(\hat{\mu}_n - \mu)}{\sqrt{\sigma^2}} \xrightarrow{\omega} N(0, 1), \qquad T_n \xrightarrow{\omega} N(0, 1), \qquad \frac{(n - 1)\hat{\xi}_n^2}{\sigma^2} \sim \chi^2_{n-1}$$

(остання — для нормальної вибірки, $\hat{\xi}_n^2$ — вибіркова дисперсія). Для поліноміальної схеми потрібна статистика, що порівнює частоти з теоретичними ймовірностями — це статистика $\chi^2$.

## §3. Статистика $\chi^2$. Теорема Пірсона

> **Означення 2 (статистика $\chi^2$ Пірсона)**
>
> Для поліноміальної схеми Бернуллі з ймовірностями $p_1, \dots, p_k$ статистикою $\chi^2$ називається
>
> $$\chi^2_k(n) = \sum_{i=1}^{k} \frac{(\nu_{ni} - np_i)^2}{np_i}.$$

Мнемонічно: $\chi^2_k(n) = \sum \dfrac{(\text{Observed} - \text{Expected})^2}{\text{Expected}}$, де $\text{Observed} = \nu_{ni}$ (спостережена частота), $\text{Expected} = np_i$ (очікувана).

> **Теорема 1 (Пірсона про статистику $\chi^2$)**
>
> Нехай $X = (\xi_1, \dots, \xi_n)$ — поліноміальна схема Бернуллі, $\nu_n = (\nu_{n1}, \dots, \nu_{nk})$, $\theta = (p_1, \dots, p_k)$, $p_i > 0$, $i = \overline{1, k}$, $\sum_{i=1}^{k} p_i = 1$. Тоді
>
> $$\chi^2_k(n) = \sum_{i=1}^{k} \frac{(\nu_{ni} - np_i)^2}{np_i} \xrightarrow{\omega} \chi^2_{k-1}, \qquad n \to \infty.$$

**Доведення**

*Примітка:* $\sum p_i = 1$, $\sum \nu_{ni} = n$.

**1. Запис через суму незалежних векторів.** Введемо вектори

$$\zeta(n) = \left(\frac{\nu_{ni} - np_i}{\sqrt{np_i}}\right)_{i=1}^{k}, \qquad \gamma_j = \left(\frac{\mathbf{1}_{\{\xi_j = x_i\}} - p_i}{\sqrt{p_i}}\right)_{i=1}^{k}, \quad j = \overline{1, n}.$$

Тоді $\mathrm{E}\gamma_j = 0$ та

$$\zeta(n) = \left(\sum_{j=1}^{n} \frac{\mathbf{1}_{\{\xi_j = x_i\}} - p_i}{\sqrt{np_i}}\right)_{i=1}^{k} = \frac{1}{\sqrt{n}} \sum_{j=1}^{n} \gamma_j, \qquad \chi^2_k(n) = \big(\zeta(n), \zeta(n)\big) = \zeta^T(n)\,\zeta(n) = \|\zeta(n)\|^2,$$

де $(\cdot, \cdot)$ — скалярний добуток.

**2. Коваріаційна матриця.** Для $l, t = \overline{1, k}$:

$$\begin{aligned} \mathrm{cov}(\gamma_j)_{lt} &= \frac{1}{\sqrt{p_l p_t}}\, \mathrm{E}\big(\mathbf{1}_{\{\xi_j = x_l\}} - p_l\big)\big(\mathbf{1}_{\{\xi_j = x_t\}} - p_t\big) \\ &= \frac{1}{\sqrt{p_l p_t}} \Big(\mathrm{E}\, \mathbf{1}_{\{\xi_j = x_l\}} \mathbf{1}_{\{\xi_j = x_t\}} - p_l p_t - p_l p_t + p_l p_t\Big) = \frac{1}{\sqrt{p_l p_t}} \Big(\mathrm{E}\, \mathbf{1}_{\{\xi_j = x_l\}}\, \delta_{lt} - p_l p_t\Big). \end{aligned}$$

Оскільки $\mathrm{E}\, \mathbf{1}_{\{\xi_j = x_l\}} = p_l$, а при $l = t$ маємо $p_l = p_t = \sqrt{p_l p_t}$, отримуємо

$$\mathrm{cov}(\gamma_j) = \big(\delta_{lt} - \sqrt{p_l p_t}\big)_{l,t=\overline{1,k}} = I - qq^T, \qquad q = (\sqrt{p_1}, \dots, \sqrt{p_k})^T, \quad \|q\|^2 = (q, q) = 1,$$

де $I$ — одинична матриця, а $qq^T$ — вироджена.

**3. Ортогональне перетворення.** За теоремою Грама–Шмідта існує ортонормований базис $U = (q_1, \dots, q_{k-1}, q)$ (ортогональна матриця, рядки якої — $q_1^T, \dots, q_{k-1}^T, q^T$), причому

$$U \cdot q = (0, \dots, 0, 1)^T.$$

За багатовимірною ЦГТ

$$\zeta(n) = \frac{1}{\sqrt{n}} \sum_{j=1}^{n} \gamma_j \xrightarrow{\omega} \xi \sim N\big(0;\, I - qq^T\big)$$

(формально такий запис не зовсім коректний, але суть зрозуміла: $\zeta^T(n)\zeta(n) \xrightarrow{\omega} (\xi, \xi)$).

Нехай $\beta = U\xi$. Тоді $\mathrm{E}\beta = U\,\mathrm{E}\xi = 0$ і

$$\begin{aligned} \mathrm{cov}\,\beta &= U\, \mathrm{cov}\,\xi\, U^T = U(I - qq^T)U^T = UU^T - Uq\,q^T U^T \\ &= I - \mathrm{diag}(0, \dots, 0, 1) = \mathrm{diag}(1, \dots, 1, 0). \end{aligned}$$

Отже, $\beta = (\beta_1, \dots, \beta_{k-1}, \beta_k)$, де $\beta_1, \dots, \beta_{k-1} \sim N(0, 1)$ незалежні, а $\beta_k = 0$.

**4. Висновок.** Оскільки $\xi = U^T\beta$,

$$(\xi, \xi) = (U^T\beta)^T (U^T\beta) = \beta^T U U^T \beta = \beta^T \beta = \sum_{i=1}^{k-1} \beta_i^2 \sim \chi^2_{k-1}.$$

Тому $\zeta^T(n)\zeta(n) = \chi^2_k(n) \xrightarrow{\omega} \chi^2_{k-1}$ при $n \to \infty$. $\blacksquare$

## §4. Критерій $\chi^2$ для простої гіпотези

Нехай $\theta = (p_1, \dots, p_k)$, $\nu_n = (\nu_{n1}, \dots, \nu_{nk})$ і перевіряємо

$$\begin{cases} H_0: \ \theta = (p_1, \dots, p_k), \\ H_1: \ \theta = (p_1^*, \dots, p_k^*) \neq (p_1, \dots, p_k). \end{cases}$$

- За $H_0$ (теорема Пірсона): $\chi^2_k(n) = \displaystyle\sum_{i=1}^{k} \frac{(\nu_{ni} - np_i)^2}{np_i} \xrightarrow{\omega} \chi^2_{k-1}$, $n \to \infty$.
- За $H_1$: $\chi^2_k(n) \xrightarrow{\text{м.н.}} +\infty$, $n \to \infty$ (бо $\nu_{ni}/n \to p_i^* \neq p_i$ для деякого $i$).

**Тест:**

$$\Big(\chi^2_k(n);\ \big[Q^{\chi^2_{k-1}}(1 - \alpha);\ +\infty\big)\Big),$$

де $Q^{\chi^2_{k-1}}(1 - \alpha)$ — квантиль рівня $1 - \alpha$ розподілу $\chi^2_{k-1}$. Гіпотезу $H_0$ відхиляємо, якщо значення статистики потрапляє в критичну область $[Q^{\chi^2_{k-1}}(1 - \alpha); +\infty)$.

> **Приклад 1 (перевірка симетричності кубика, $n = 600$ підкидань)**
>
> Перевіряємо $H_0: \ p_i = \frac{1}{6}$ проти $H_1: \ p_i \neq \frac{1}{6}$ (для деякого $i$), $k = 6$.
>
> | Грань $i$ | 1 | 2 | 3 | 4 | 5 | 6 | $\Sigma$ |
> |---|---|---|---|---|---|---|---|
> | $\nu_{ni} = O$ | 104 | 108 | 97 | 103 | 94 | 94 | 600 |
> | $np_i = E$ | 100 | 100 | 100 | 100 | 100 | 100 | |
> | $(E - O)^2$ | 16 | 64 | 9 | 9 | 36 | 36 | |
> | $\dfrac{(E - O)^2}{E}$ | $\frac{16}{100}$ | $\frac{64}{100}$ | $\frac{9}{100}$ | $\frac{9}{100}$ | $\frac{36}{100}$ | $\frac{36}{100}$ | 1,7 |
>
> $$\sum \frac{(E - O)^2}{E} = 1{,}7 = \chi^2_k(n) \ \approx \ \chi^2_{k-1}.$$
>
> Для $\alpha = 5\%$ квантиль $Q^{\chi^2_5}(0{,}95) = 11{,}0705 > \chi^2_k(n) = 1{,}7$, тому значення статистики не потрапляє в критичну область $\Rightarrow$ гіпотезу $H_0: \ p_i = \frac{1}{6}$ не відхиляємо (даних для висновку, що кубик несиметричний, немає).

## §5. Критерій $\chi^2$ узгодженості з розподілом

Нехай $X = (\xi_1, \dots, \xi_n)$ — кратна вибірка, $\xi_j \sim F$ (довільний, зокрема неперервний розподіл). Розіб'ємо числову вісь на скінченну кількість множин, що не перетинаються:

$$\mathbb{R} = \bigcup_{i=1}^{k} \Delta_i, \qquad \Delta_i \cap \Delta_j = \varnothing \ (i \neq j).$$

Перейдемо до дискретної вибірки $\tilde{X} = (\tilde{\xi}_1, \dots, \tilde{\xi}_n)$, $\tilde{\xi}_j \in \{x_1, \dots, x_k\}$, де

$$x_i = \{\xi_j \in \Delta_i\}, \qquad \nu_{ni} = \sum_{j=1}^{n} \mathbf{1}_{\{\xi_j \in \Delta_i\}}.$$

Гіпотеза $H_0: \ \xi_j \sim F$ (проти заперечення) замінюється на

$$\begin{cases} H_0: \ p_i = F(\Delta_i), \\ H_1: \ \text{заперечення}. \end{cases}$$

**Тест:**

$$\left(\hat{\chi}^2_k(n) = \sum_{i=1}^{k} \frac{(\nu_{ni} - np_i)^2}{np_i};\ \big[Q^{\chi^2_{k-1}}(1 - \alpha);\ +\infty\big)\right), \qquad p_i = F(\Delta_i).$$

## §6. $\chi^2$ тести для декількох вибірок та серій випробувань Бернуллі

Нехай маємо $m$ серій випробувань (вибірок)

$$(\xi_{li})_{\substack{l=\overline{1,m} \\ i=\overline{1,n_l}}} = (\xi_1, \dots, \xi_m),$$

де $n_l$ — кількість елементів у $\xi_l$, $l = \overline{1, m}$, причому

$$\xi_{lj} \in \{x_1, \dots, x_k\}, \qquad P(\xi_{lj} = x_i) = p_i.$$

Позначимо

$$\nu_{li} = \sum_{j=1}^{n_l} \mathbf{1}_{\{\xi_{lj} = x_i\}}, \qquad \nu_l(n_l) = (\nu_{l1}, \dots, \nu_{lk}), \qquad \nu_n = \big(\nu_1(n_1), \dots, \nu_m(n_m)\big), \quad n = \sum_{l=1}^{m} n_l.$$

Перевіряється **тест про однорідність вибірок**:

$$\begin{cases} H_0: \ P(\xi_{lj} = x_i) = p_i \ \ (\text{однакові для всіх } l), \\ H_1: \ \text{заперечення}, \end{cases} \qquad \theta = (p_1, \dots, p_k) \text{ — вектор}.$$

### 1) Якщо $\theta$ відоме

$$\hat{\chi}^2_k(m) = \sum_{i=1}^{k} \sum_{l=1}^{m} \frac{(\nu_{li} - n_l p_i)^2}{n_l p_i} \xrightarrow{\omega} \sum_{l=1}^{m} \chi^2_{k-1} = \chi^2_{m(k-1)}, \qquad n \to \infty$$

(для кожної вибірки діє теорема Пірсона, вибірки незалежні). Тест:

$$\Big(\hat{\chi}^2_k(m);\ \big[Q^{\chi^2_{m(k-1)}}(1 - \alpha);\ +\infty\big)\Big), \qquad \alpha = 0{,}01.$$

### 2) Якщо $\theta$ — невідомий

Статистика

$$\hat{\chi}^2_k(m) = \sum_{i=1}^{k} \sum_{l=1}^{m} \frac{(\nu_{li} - n_l \hat{p}_i)^2}{n_l \hat{p}_i}.$$

За методом максимальної правдоподібності оцінюємо $\theta$ за об'єднаною вибіркою:

$$\hat{\theta}_{\text{ОМВ}} = \left(\frac{\nu_{\cdot 1}}{n}, \dots, \frac{\nu_{\cdot k}}{n}\right) = (\hat{p}_1, \dots, \hat{p}_k), \qquad \nu_{\cdot i} = \sum_{l=1}^{m} \nu_{li}.$$

Тоді

$$\hat{\chi}^2_{k,m}(\hat{\theta}_{\text{ОМВ}}) = \sum_{i=1}^{k} \sum_{l=1}^{m} \frac{(\nu_{li} - n_l \hat{p}_i)^2}{n_l \hat{p}_i} \xrightarrow{\omega} \chi^2_{(m-1)(k-1)}, \qquad n \to \infty$$

(число ступенів вільності зменшується на $k - 1$ — кількість оцінених параметрів).

Тест:

$$\Big(\hat{\chi}^2_{k,m};\ \big[Q^{\chi^2_{(m-1)(k-1)}}(1 - \alpha);\ +\infty\big)\Big).$$

## §7. Критерій $\chi^2$ про незалежність

> **Приклад 2 (інтернет-магазин)**
>
> Нехай $X = (\xi_1, \dots, \xi_n)$ та $Y = (\eta_1, \dots, \eta_n)$, де $(\xi_j, \eta_j)$ — пара товарів у кошику. Тут
>
> - $\xi_j$ — поліноміальна схема Бернуллі зі значеннями $(x_1, \dots, x_k)$ та ймовірностями $p_1, \dots, p_k$;
> - $\eta_j$ — поліноміальна схема Бернуллі зі значеннями $(y_1, \dots, y_m)$ та ймовірностями $q_1, \dots, q_m$.
>
> Перевіряється гіпотеза $H_0: \ X$ та $Y$ незалежні.
>
> Якщо знаходимо *залежні* товари, це можна використати так:
>
> - підбирати фільтри;
> - маркетинг на пари товарів;
> - можемо планувати закупку / склад.
