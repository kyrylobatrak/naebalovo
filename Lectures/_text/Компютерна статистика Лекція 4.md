### Довірчі інтервали для середнього і ймовірності успіху; метод моментів

> У цій лекції вводиться поняття **довірчого інтервалу**, будується довірчий інтервал для середнього $\mu$ (з відомою і з невідомою дисперсією, за допомогою **теореми Слуцького**) та для ймовірності успіху $p$ у схемі Бернуллі; далі викладається **метод моментів**: теоретичні й вибіркові моменти, їхні властивості (точні й асимптотичні), загальна конструкція оцінки методу моментів та її консистентність.

## §1. Довірчі інтервали

**Означення (довірчий інтервал)**

Нехай $\theta$ — невідомий параметр розподілу вибірки $X = (\xi_1, \ldots, \xi_n)$, і нехай $(\hat\theta_1, \hat\theta_2)$ — пара статистик, $\hat\theta_1 \le \hat\theta_2$. Інтервал $[\hat\theta_1, \hat\theta_2]$ називається **довірчим інтервалом рівня** $\alpha$ для параметра $\theta$, якщо

$$P\big(\theta \in [\hat\theta_1, \hat\theta_2]\big) \longrightarrow \alpha, \qquad n \to \infty.$$

Нагадаємо наслідок ЦГТ для вибіркового середнього: якщо $\xi_1, \ldots, \xi_n$ — незалежні в.в., $E\xi_i = \mu$, $D\xi_i = \sigma^2$, $S_n = \sum_{i=1}^n \xi_i$ і $\hat\mu_n = \frac{1}{n} S_n$, то

$$\frac{S_n - ES_n}{\sqrt{DS_n}} = \frac{\sqrt{n}(\hat\mu_n - \mu)}{\sigma} \xrightarrow{\ \omega\ } N(0,1), \qquad n \to \infty.$$

## §2. Побудова довірчого інтервалу для середнього ($\sigma$ відоме)

**Задача**

Побудувати довірчий інтервал для параметра $\mu$ з рівнем $\alpha = 0{,}95$ за умов $E\xi_i = \mu$, $D\xi_i = \sigma^2$, де $\sigma$ — *відоме*.

Позначимо $\zeta_n = \dfrac{\sqrt{n}(\hat\mu_n - \mu)}{\sigma} \xrightarrow{\ \omega\ } \zeta \sim N(0,1)$, $n \to \infty$. Отже, $P(|\zeta_n| < x_\alpha) \to P(|\zeta| < x_\alpha)$, і природно підібрати $x_\alpha$ так, щоб $P(|\zeta| < x_\alpha) = \alpha$.

**Означення (квантиль)**

Нехай $\xi$ — випадкова величина з функцією розподілу $F$, тобто $P(\xi < t) = F(t)$. **Квантилем рівня** $\alpha$ випадкової величини $\xi$ називається таке $x$, що $P(\xi < x) = \alpha$; позначення: $x = Q^F(\alpha)$.

Оскільки $\zeta \sim N(0,1)$ симетрична відносно нуля,

$$P(|\zeta| < x_\alpha) = \alpha \iff P(\zeta < x_\alpha) = \alpha + \frac{1-\alpha}{2} = \frac{1+\alpha}{2},$$

[Графік щільності стандартного нормального розподілу: область між $-x_\alpha$ і $x_\alpha$ заштрихована й позначена $\alpha$; на кожному з двох хвостів площа $\frac{1-\alpha}{2}$.]

звідки

$$x_\alpha = Q^{N(0,1)}\left(\frac{1+\alpha}{2}\right) = Q^{|\zeta|}(\alpha).$$

З нерівності $|\zeta_n| < x_\alpha$, тобто $-x_\alpha < \dfrac{\sqrt{n}(\hat\mu_n - \mu)}{\sigma} < x_\alpha$, виражаємо $\mu$:

$$\hat\mu_n - \frac{x_\alpha}{\sqrt{n}}\sigma \ <\ \mu\ <\ \hat\mu_n + \frac{x_\alpha}{\sqrt{n}}\sigma,$$

тобто

$$P\left(\mu \in \left[\hat\mu_n \pm \frac{x_\alpha}{\sqrt{n}}\sigma\right]\right) \longrightarrow \alpha, \qquad n \to \infty,$$

і шуканий **довірчий інтервал**:

$$\left\{\hat\mu_n \pm \frac{x_\alpha}{\sqrt{n}}\sigma\right\}.$$

## §3. Випадок невідомої $\sigma$: теорема Слуцького

**Зауваження: що робити, коли $\sigma$ невідома**

Дисперсію $\sigma^2$ можна замінити консистентною оцінкою, наприклад

$$\hat S_n^2 = \frac{1}{n-1}\sum_{i=1}^n (\xi_i - \hat\mu_n)^2 \xrightarrow{\ P\ } \sigma^2, \qquad n \to \infty.$$

За **теоремою Слуцького** (якщо $Y_n \xrightarrow{\ \omega\ } Y$ і $c_n \xrightarrow{\ P\ } c \ne 0$, то $Y_n / c_n \xrightarrow{\ \omega\ } Y/c$):

$$\frac{\sqrt{n}(\hat\mu_n - \mu)}{\sqrt{\hat S_n^2}} = \underbrace{\frac{\sqrt{n}(\hat\mu_n - \mu)}{\sigma}}_{\xrightarrow{\ \omega\ } N(0,1)} \cdot \underbrace{\sqrt{\frac{\sigma^2}{\hat S_n^2}}}_{\xrightarrow{\ P\ } 1,\ n \to \infty} \xrightarrow{\ \omega\ } N(0,1).$$

Отже, у цьому випадку довірчий інтервал:

$$\left\{\hat\mu_n \pm \frac{x_\alpha}{\sqrt{n}}\sqrt{\hat S_n^2}\right\}.$$

## §4. Приклад: довірчий інтервал для ймовірності успіху

**Приклад (розподіл Бернуллі)**

Нехай $\xi_i \sim B(p)$, $\hat p_n = \frac{1}{n}\sum_i \xi_i$. Тоді $E\hat p_n = p$, $D\hat p_n = \dfrac{p(1-p)}{n} \to 0$, $n \to \infty$, тому $\hat p_n \xrightarrow{\ P\ } p$; а за теоремою Колмогорова про ПЗВЧ навіть $\hat p_n \xrightarrow{\text{м.н.}} p$, $n \to \infty$. За ЦГТ

$$\frac{S_n - ES_n}{\sqrt{DS_n}} = \frac{\sqrt{n}(\hat p_n - p)}{\sqrt{p(1-p)}} \xrightarrow{\ \omega\ } N(0,1).$$

Формально це дає довірчий інтервал *параметра $p$, якого ми не знаємо*: $\left\{\hat p_n \pm \frac{x_\alpha}{\sqrt{n}}\sqrt{p(1-p)}\right\}$ — але він сам містить невідоме $p$. За теоремою Слуцького замінюємо $p$ під коренем на його консистентну оцінку $\hat p_n$, і остаточно:

$$\left\{\hat p_n \pm \frac{x_\alpha}{\sqrt{n}}\sqrt{\hat p_n(1-\hat p_n)}\right\}.$$

## §5. Метод моментів: означення

**Означення (теоретичний і центрований момент)**

Нехай $\xi$ — випадкова величина. **$k$-тим теоретичним моментом** величини $\xi$ називається $\mu_k = E\xi^k$. **Центрованим $k$-тим моментом** називається

$$\mu_k^\circ = E(\xi - \mu_1)^k = E(\xi - E\xi)^k.$$

Зокрема, $\mu_1 = E\xi$, $\mu_2^\circ = E(\xi - E\xi)^2 = D\xi$.

**Похідні коефіцієнти**

На основі моментів означають ще декілька числових характеристик розподілу (тут $\sigma = \sqrt{\mu_2^\circ}$, $m_{1/2}$ — медіана):

$$K_v = \frac{\sigma}{\mu_1} = \frac{\sqrt{\mu_2^\circ}}{\mu_1} \ \text{(коеф. варіації)}, \qquad K_s = 3(\mu_1 - m_{1/2}) \ \text{(коеф. скошеності)},$$

$$K_a = \frac{\mu_3^\circ}{\sigma^3} \ \text{(коеф. асиметрії; } K_a = 0 \text{ для симетричних розподілів)}, \qquad K_e = \frac{\mu_4^\circ}{\sigma^4} \ \text{(коеф. ексцесу)}.$$

**Означення (вибірковий момент)**

Нехай $X = (\xi_1, \ldots, \xi_n)$ — вибірка. **Емпіричним (вибірковим) $k$-тим моментом** вибірки $X$ називається

$$\hat\mu_{n,k} = \frac{1}{n}\sum_{i=1}^n \xi_i^k,$$

а **вибірковим центрованим $k$-тим моментом** —

$$\hat\mu_{n,k}^\circ = \frac{1}{n}\sum_{i=1}^n \big(\xi_i - \hat\mu_{n,1}\big)^k.$$

**Приклад**

При $k = 1$: $\hat\mu_{n,1} = \hat\mu_n = \frac{1}{n}\sum_i \xi_i$ — звичайне вибіркове середнє. При $k = 2$:

$$\hat\mu_{n,2}^\circ = \hat\sigma_n^2 = \frac{1}{n}\sum_{i=1}^n (\xi_i - \hat\mu_n)^2 = \hat\mu_{n,2} - (\hat\mu_n)^2$$

— **зміщена** вибіркова дисперсія (для *незміщеної* вибіркової дисперсії ділять не на $n$, а на $n-1$, див. §6).

## §6. Властивості вибіркових моментів

**Теорема (про властивості вибіркових моментів)**

Нехай $\xi_1, \ldots, \xi_n$ — кратна вибірка. Тоді:

1) $E\hat\mu_{n,k} = \mu_k$;
2) $D\hat\mu_{n,k} = \dfrac{1}{n}\big(\mu_{2k} - \mu_k^2\big)$;
3) $E\hat\sigma_n^2 = \dfrac{n-1}{n}\sigma^2$, де $\hat\sigma_n^2 = \frac{1}{n}\sum_i (\xi_i - \hat\mu_n)^2$; тому незміщеною є оцінка $\hat S_n^2 = \frac{1}{n-1}\sum_i (\xi_i - \hat\mu_n)^2$, $E\hat S_n^2 = \sigma^2$;
4) $D\hat\sigma_n^2 = \dfrac{n-1}{n^3}\Big((n-1)\mu_4^\circ - (n-3)\sigma^4\Big)$.

***Доведення (пп. 1–3; п. 4 — самостійно)***

**1)**

$$E\hat\mu_{n,k} = E\left[\frac{1}{n}\sum_{i=1}^n \xi_i^k\right] = \frac{1}{n}\sum_{i=1}^n E\xi_i^k = \frac{1}{n}\sum_{i=1}^n \mu_k = \mu_k.$$

**2)** Оскільки $\xi_i$ незалежні, а $D\xi_i^k = E\xi_i^{2k} - (E\xi_i^k)^2 = \mu_{2k} - \mu_k^2$:

$$D\hat\mu_{n,k} = D\left[\frac{1}{n}\sum_{i=1}^n \xi_i^k\right] = \frac{1}{n^2}\sum_{i=1}^n D\xi_i^k = \frac{1}{n^2}\sum_{i=1}^n \big(\mu_{2k} - \mu_k^2\big) = \frac{1}{n}\big(\mu_{2k} - \mu_k^2\big).$$

**3)** Використовуючи пп. 1–2 при $k = 1, 2$:

$$E\hat\sigma_n^2 = E\hat\mu_{n,2} - E(\hat\mu_{n,1})^2 = \mu_2 - \Big(D\hat\mu_{n,1} + (E\hat\mu_{n,1})^2\Big) = \mu_2 - \frac{\mu_2 - \mu_1^2}{n} - \mu_1^2 = \Big(1 - \frac{1}{n}\Big)\sigma^2 = \frac{n-1}{n}\sigma^2.$$

Звідси $E\big[\frac{n}{n-1}\hat\sigma_n^2\big] = \sigma^2$, тобто $\hat S_n^2 = \frac{n}{n-1}\hat\sigma_n^2 = \frac{1}{n-1}\sum_i (\xi_i - \hat\mu_n)^2$ — незміщена оцінка $\sigma^2$. $\blacksquare$

## §7. Асимптотичні властивості емпіричних моментів

**Теорема (про асимптотичні властивості емпіричних моментів)**

Нехай $X = (\xi_1, \ldots, \xi_n)$ — кратна вибірка. Тоді:

1) якщо $E|\xi|^k < \infty$, то $\hat\mu_{n,k} \xrightarrow{\text{м.н.}} \mu_k$, $n \to \infty$;
2) якщо $E|\xi|^{2k} < \infty$, то

$$\frac{\sqrt{n}(\hat\mu_{n,k} - \mu_k)}{\sqrt{\mu_{2k} - \mu_k^2}} \xrightarrow{\ \omega\ } N(0,1), \qquad n \to \infty.$$

***Доведення***

Пункт 2) — безпосередній наслідок ЦГТ, застосованої до $\xi_i^k$. Пункт 1) — наслідок теореми Колмогорова про ПЗВЧ, застосованої до $\xi_i^k$.

Ці факти узагальнюються на *вектор* моментів: позначимо $\mu^{(d)} = (\mu_1, \ldots, \mu_d)$ — теоретичний вектор моментів, і $\hat\mu_n^{(d)} = (\hat\mu_{n,1}, \ldots, \hat\mu_{n,d})$ — вектор емпіричних моментів.

**Теорема (векторна версія)**

Нехай $X$ — кратна вибірка. Тоді:

a) якщо $E|\xi|^d < \infty$, то $\hat\mu_n^{(d)} \xrightarrow{\text{м.н.}} \mu^{(d)}$;
b) якщо $E|\xi|^{2d} < \infty$, то

$$\sqrt{n}\big(\hat\mu_n^{(d)} - \mu^{(d)}\big) \xrightarrow{\ \omega\ } N\big(\bar 0, V^{(d)}\big), \qquad V^{(d)} = \big(\mu_{l+k} - \mu_l\mu_k\big)_{l=\overline{1,d},\ k=\overline{1,d}}.$$

***Доведення***

**а)** За скалярною теоремою (п. 1) $\hat\mu_{n,k} \xrightarrow{\text{м.н.}} \mu_k$ для кожного $k = \overline{1,d}$ окремо, тому

$$P\Big(\lim_{n\to\infty} \hat\mu_n^{(d)} = \mu^{(d)}\Big) = P\left(\bigcap_{k=1}^d \Big\{\exists \lim_{n\to\infty} \hat\mu_{n,k} = \mu_k\Big\}\right) = 1$$

(перетин скінченної кількості подій ймовірності $1$ має ймовірність $1$).

**б)** Позначимо $\zeta_i = \big(\xi_i^k - \mu_k\big)_{k=1}^d \in \mathbb{R}^d$, $i = \overline{1,n}$ — незалежні однаково розподілені випадкові вектори, $E\zeta_i = \bar 0$. Обчислимо коваріаційну матрицю:

$$\operatorname{cov}\zeta_i = E\big(\zeta_i\zeta_i^{\mathsf T}\big) = E\Big[(\xi_i^k - \mu_k)(\xi_i^l - \mu_l)\Big]_{k,l=1}^d = E\big[\xi_i^{k+l} - \xi_i^k\mu_l - \mu_k\xi_i^l + \mu_k\mu_l\big]_{k,l}$$

$$= \big[\mu_{k+l} - \mu_k\mu_l - \mu_k\mu_l + \mu_k\mu_l\big]_{k,l} = \big(\mu_{k+l} - \mu_k\mu_l\big)_{k,l=1}^d = V^{(d)}.$$

За багатовимірною ЦГТ,

$$\sqrt{n}\big(\hat\mu_n^{(d)} - \mu^{(d)}\big) = \frac{1}{\sqrt{n}}\sum_{i=1}^n \zeta_i \xrightarrow{\ \omega\ } N\big(\bar 0, V^{(d)}\big), \qquad n \to \infty. \qquad \blacksquare$$

## §8. Метод моментів: загальна конструкція

**Ідея методу моментів**

Нехай розподіл вибірки залежить від параметра $\theta \in \Theta$, і нехай

$$\mu^{(d)}(\theta) = \big(\mu_1(\theta), \ldots, \mu_d(\theta)\big) : \Theta \to \mathbb{R}^d$$

— вектор перших $d$ теоретичних моментів як функція параметра. Припустимо, що існує неперервне відображення $T_d : \mathbb{R}^d \to \Theta$, яке «обертає» цю залежність:

$$T_d\big(\mu^{(d)}(\theta)\big) = \theta \qquad \forall \theta \in \Theta.$$

**Означення (оцінка методу моментів)**

**Оцінкою методу моментів** (ОММ) параметра $\theta$ називається

$$\hat\theta_{\text{ОММ}} = T_d\big(\hat\mu_n^{(d)}\big), \qquad \hat\mu_n^{(d)} = (\hat\mu_{n,1}, \ldots, \hat\mu_{n,d}).$$

**Схема побудови ОММ**

1) Обчислюємо теоретичні моменти як функції параметра: $\mu_k(\theta) = E_\theta\, \xi_1^k$, $k = \overline{1,d}$.
2) Виражаємо $\theta$ через $E_\theta \xi_1^k$, $k = \overline{1,d}$ (тобто знаходимо $T_d$).
3) У знайдених виразах замінюємо $E_\theta \xi_1^k$ на вибіркові моменти $\hat\mu_{n,k} = \frac{1}{n}\sum_{i=1}^n \xi_i^k$.

**Теорема (консистентність ОММ)**

Нехай $X$ — кратна вибірка, $T_d$ — неперервне відображення, і $E|\xi|^d < \infty$. Тоді

$$\hat\theta_{\text{ОММ}} \xrightarrow{\text{м.н.}} \theta, \qquad n \to \infty, \qquad \forall \theta \in \Theta.$$

***Доведення***

За теоремою про асимптотичні властивості емпіричних моментів (векторна версія, п. а) маємо $\hat\mu_n^{(d)} \xrightarrow{\text{м.н.}} \mu^{(d)}(\theta)$. Оскільки неперервне відображення зберігає збіжність (майже напевно, за ймовірністю і слабку), за теоремою про неперервне відображення

$$\hat\theta_{\text{ОММ}} = T_d\big(\hat\mu_n^{(d)}\big) \xrightarrow{\text{м.н.}} T_d\big(\mu_1(\theta), \ldots, \mu_d(\theta)\big) = \theta, \qquad \forall \theta \in \Theta. \qquad \blacksquare$$

## §9. Приклади методу моментів

**Приклад 1 ($\xi_i \sim U[a,b]$)**

Знайдемо $\hat a_{\text{ОММ}}$, $\hat b_{\text{ОММ}}$.

**Кроки 1–2.** $\mu = E\xi_i = \dfrac{a+b}{2}$, $\sigma^2 = D\xi_i = \dfrac{(b-a)^2}{12}$. З першого рівняння $a = 2\mu - b$; підставляючи в друге:

$$\sigma^2 = \frac{(2b - 2\mu)^2}{12} = \frac{(b-\mu)^2}{3} \implies (b-\mu)^2 = 3\sigma^2 \implies b - \mu = \pm\sqrt{3\sigma^2}.$$

Оскільки $a < b$, беремо $b = \mu + \sqrt{3\sigma^2}$, звідки $a = 2\mu - b = \mu - \sqrt{3\sigma^2}$.

**Крок 3.**

a) Підставляючи вибіркові моменти напряму:

$$\hat b_{\text{ОММ}} = \hat\mu_n + \sqrt{3\big(\hat\mu_{n,2} - \hat\mu_{n,1}^2\big)}, \qquad \hat a_{\text{ОММ}} = \hat\mu_n - \sqrt{3\big(\hat\mu_{n,2} - \hat\mu_{n,1}^2\big)}.$$

b) Або, використовуючи консистентну (незміщену) оцінку дисперсії $\hat S_n^2 \xrightarrow{\ P\ } \sigma^2$:

$$\hat b_{\text{ОММ}} = \hat\mu_n + \sqrt{3\hat S_n^2}, \qquad \hat a_{\text{ОММ}} = \hat\mu_n - \sqrt{3\hat S_n^2}.$$

Обидва варіанти консистентні (різняться лише на доданок порядку $1/n$ всередині кореня).

**Приклад 2 (параметризація через гамма-функцію)**

Нехай $\xi_i \sim U\big[\Gamma(a), \Gamma(b)\big]$, де $\Gamma$ — гамма-функція, $1 \le a \le b$. Так само, як у прикладі 1,

$$\Gamma(a) = \hat\mu_n - \sqrt{3\hat S_n^2}, \qquad \Gamma(b) = \hat\mu_n + \sqrt{3\hat S_n^2}.$$

Але тепер, на відміну від прикладу 1, обернути гамма-функцію аналітично неможливо: оцінки $\hat a_{\text{ОММ}}$, $\hat b_{\text{ОММ}}$ доводиться знаходити *чисельно*, розв'язуючи ці два рівняння числовими методами.
