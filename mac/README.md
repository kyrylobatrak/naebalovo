# AI overlay на macOS

Той самий оверлей, що й на Windows: код вікна, Claude, Whisper і озвучення спільний.
У цій папці лише те, що на Mac працює інакше (`macos.py`), запуск і залежності.

## Встановлення

1. Python 3.10+ (`brew install python@3.12`) і Claude Code (`claude` у терміналі, вхід в акаунт).
2. Подвійний клік по `mac/run.command`. Якщо macOS не дає запустити, виконайте в терміналі:
   `chmod +x mac/run.command`, а потім відкрийте файл через ПКМ → «Відкрити».
   Перший запуск створює `.venv-mac` і ставить залежності.

## Дозволи (Системні параметри → Приватність і безпека)

Дозволи видаються програмі, з якої запущено оверлей (зазвичай Terminal). Після зміни дозволу перезапустіть оверлей.

| Дозвіл | Для чого |
|---|---|
| Мікрофон | ваш голос |
| Універсальний доступ (Accessibility) | гарячі клавіші й кнопки миші |
| Запис екрана | скріншот для Claude (📷 / Ctrl+Option+S) |

## Кнопка миші: закрити все / запустити знову

`run.command` запускає оверлей через `mac/overlay-guard` (код: `mac/overlay_guard.cpp`; він збирається сам при першому запуску, потрібні Xcode Command Line Tools: `xcode-select --install`).

| Дія | Що відбувається |
|---|---|
| Бічна кнопка «вперед», коли оверлей працює | закриваються оверлей і всі його процеси (Claude Code, node…) |
| Та сама кнопка, коли оверлей закритий | оверлей запускається знову |
| Control + кнопка | закривається все разом з охоронцем |

Кнопку можна змінити в `run.command`: `GUARD_BUTTON=mouse4` (бічна «назад») або `mouse3` (клік колесом). Потрібен той самий дозвіл «Універсальний доступ». Без нього охоронець покаже попередження і запустить оверлей без кнопки.

## Звук співрозмовника

macOS не вміє записувати звук колонок сама. Тому потрібен віртуальний пристрій [BlackHole](https://github.com/ExistentialAudio/BlackHole) (`brew install blackhole-2ch`):

1. «Налаштування Audio MIDI» → «+» → «Створити пристрій із кількома виходами» → відмітити колонки/навушники і BlackHole 2ch.
2. Вибрати цей пристрій як вихід звуку системи.

Оверлей сам знайде BlackHole (назву можна змінити в `core.py`: `mac_system_device`).
Без нього працюють мікрофон, набрані запитання, файли й скріншоти.

## Відмінності від Windows

- **Гарячі клавіші:** Ctrl — це Control, Alt — це Option, Win — це Cmd. За замовчуванням Control+Option+…
- **Скріншот** робиться через `screencapture -x`, тому звуку затвора немає (на M-процесорах і Intel).
- **Приховування від демонстрації** вмикається через `NSWindow.sharingType = none`. На macOS 15 і новіших програми, що захоплюють екран через ScreenCaptureKit, можуть усе одно показувати вікно. Перед важливою розмовою перевірте це у своїй програмі для дзвінків.
- **Whisper** працює на процесорі (модель `small`, CUDA на Mac немає).
- **Аудіопристрої:** якщо змінити мікрофон чи навушники під час роботи, перезапустіть оверлей.
